# Naveen Tadaka | Portfolio

A premium, minimal, and futuristic portfolio website showcasing advanced web animations, kinetic typography, and a seamless user experience.

## ✨ Features

- **Cinematic Transitions**: A unique "zoom-through" transition from the Hero section into the About section popup, emerging from the center of the letter "A".
- **Dynamic 3D Background**: Interactive background powered by Three.js.
- **Horizontal Scroll Skills**: A smooth, pinned horizontal skill section featuring 4 categorized panels (Programming, Databases, Technologies, IDE).
- **Smooth Content Reveal**: Staggered text reveals with blur effects and GSAP-powered micro-animations.
- **Precision Scrolling**: Integrated with Lenis for a buttery-smooth vertical and horizontal scrolling experience.
- **Responsive Design**: Fully responsive layout tailored for high-end cinematic displays and mobile devices.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)
- **Scroll Logic**: [ScrollTrigger](https://greensock.com/scrolltrigger/) & [Lenis](https://github.com/darkroomengineering/lenis)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Fonts**: Space Grotesk (Google Fonts)

## 📁 Project Structure

- `index.html`: Main structure and content.
- `style.css`: Modern design system and layout.
- `script.js`: Core initialization and scroll-sync logic.
- `animations.js`: Dedicated GSAP animation engine and sequence management.
- `threeScene.js`: Three.js background canvas implementation.

## 🎨 Design Philosophy

The project follows a **Minimal-Futuristic** aesthetic, characterized by:
- Deep noir backgrounds with subtle gradients.
- High-contrast typography with variable weights.
- Motion-driven storytelling where sections emerge and transform based on user interaction.
