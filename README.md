## `00` — OVERVIEW

> *Not just a portfolio. A cinematic, scroll-driven experience engineered frame-by-frame.*

This isn't a template. Every pixel, every transition, every micro-interaction was handcrafted from scratch — zero frameworks, zero libraries for UI, pure vanilla architecture. Built to feel like a film, scroll like butter, and perform like a machine.

## `02` — SIGNATURE EFFECTS

<table>
<tr>
<td width="50%">

### 🎬 Cinematic Layer
- **Film Grain Overlay** — SVG noise at 3.5% opacity
- **Vignette** — Radial gradient edge darkening
- **Custom Cursor** — Dot + ring with `mix-blend-mode: difference`
- **Magnetic Pull** — Cursor gravitates to interactive elements
- **Smooth Scrollbar** — Custom-styled thin scrollbar

</td>
<td width="50%">

### ✦ Motion System
- **Zoom-Through Transition** — 300x scale into about section
- **Blur Cascade Reveal** — Staggered text with `blur(10px)` to sharp
- **Horizontal Pin-Scroll** — Skills section at 300vw width
- **Pin-Stack Cards** — Projects stack with scale + rotation
- **Stat Counter Animation** — Numbers count up on viewport entry

</td>
</tr>
<tr>
<td width="50%">

### ◈ Typography & Color
- **Space Grotesk** — Variable weight (300–700)
- **Gradient Text** — Animated shimmer on key elements
- **Typing Cursor** — Blinking cursor on subtitle
- **Wipe-Reveal Lines** — Panel titles with animated underline
- **Hero Shimmer** — Moving gradient highlight on name

</td>
<td width="50%">

### ⚡ Performance
- **Zero UI Frameworks** — Pure HTML/CSS/JS
- **GPU-Accelerated** — `will-change` + `force3D`
- **Mobile Optimized** — Effects disabled on touch devices
- **Lazy Animations** — ScrollTrigger-driven, nothing runs offscreen
- **Single Pin Architecture** — Minimal DOM reflow

</td>
</tr>
